Nombre del proyecto: AnimaHub Registro de Mascotas Para Gente Solitaria o en sus siglas (AHRMPGS)

Objetivo del proyecto:
Desarrollar una aplicación simple web de idealidad interactiva que permita a los usuarios a traves de un formulario generar algo en la pagina con una validación, errores, estructuración de carpetas, diseño decente, DOM, eventos (botones), CRUD y localStorage.

Requerimientos Cumplidos:
-Las carpetas fueron separadas en:
    -CSS | Para el diseño web
    -Scripts | Para las funciones de la página como validaciones, botones, DOM, etc.

-DOM, interacciones, formulario: Se cumplio con las necesidades establecidas, la pagina presenta un montón de casillas para rellenar, tiene botones con los que interactuar, sea para registrar o cambiar la vista, y tiene cosas innecesarias pero divertidas como la barra de filtro de busqueda y el boton de like y/o reporte.

-Validaciones: Todas las casillas presentan un tipo de validaciones, registros no pueden suceder de forma correcta si es que al menos una no cumple con los requisitos, sea tamaño, que el numero sea negativo o que directamente no este rellenada, esto con un mensaje para que el usuario sepa que falta.

-localStorage: Se uso localStorage para guardar de forma transitiva los datos y que se vieran en la lista de registros.

-Innovación: La barra filtradora de registro y el boton de like y reporte.

1. Clona este repositorio en tu máquina.
2. Abre una terminal en la raíz de la carpeta `AnimaHub_SC`.
3. Instala las dependencias del servidor local ejecutando:
   ```bash
   npm install
